## Objective
This repository is a way to collect information on different AI models developed
for analyzing feline small intestinal biopsies. Each ai model has a folder, 
that for the more complex models contains it's own README on model objectives & intended use, links to slide decks
with SOPs, info on model type and platform, training, tuning and testing 
strategies and case material used
for development and testing.

### Models
- tissue_vs_glass (traditional ML)
- duplicates (traditional (rule-based) programming)
